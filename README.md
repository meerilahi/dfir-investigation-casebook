# DFIR Investigation Casebook

A growing collection of hands-on cybersecurity investigations focused on **Digital Forensics and Incident Response (DFIR)**.

## Investigations

Each case documents the analysis of one or more artifacts, evidence-based findings, indicators of compromise (IOCs), and relevant defensive recommendations.

Cases may cover:
- Phishing email analysis
- Malicious documents and Windows artifacts
- Network traffic and memory forensics
- Incident investigation and timeline reconstruction

## Methodology

Investigations use appropriate forensic tools and documented workflows. Findings are supported by evidence, with limitations and uncertainty clearly identified.

## Disclaimer

This repository is for educational and defensive cybersecurity purposes. Potentially malicious artifacts are handled in controlled environments. Published evidence may be sanitized to protect sensitive information and prevent harm.
